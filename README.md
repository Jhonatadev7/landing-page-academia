🏋️‍♂️ Academia PowerFit
Uma Landing Page moderna e responsiva para uma academia, desenvolvida com foco em conversão e experiência do usuário. O projeto apresenta informações sobre a academia, planos de assinatura e um formulário de contato funcional com navegação suave.

🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando as tecnologias fundamentais da web:

HTML5: Estruturação semântica de conteúdo.

CSS3: Estilização personalizada, layout Flexbox e design moderno.

JavaScript (Vanilla): Lógica para rolagem suave (smooth scroll) e interatividade básica.

🛠️ Funcionalidades
Navegação Inteligente: Menu com links internos para seções específicas.

Chamada para Ação (CTA): Botão "Matricule-se" na seção Hero que direciona o usuário automaticamente para o formulário.

Design Limpo: Layout focado em legibilidade e apresentação de planos.

Formulário de Contato: Preparado para validação de campos obrigatórios.

📂 Estrutura de Arquivos
Plaintext
├── index.html   # Estrutura principal da página
├── style.css    # Estilização e identidade visual
└── script.js    # Lógica de comportamento e navegação
🏁 Como Rodar o Projeto
Clone este repositório:

Bash
git clone https://github.com/seu-usuario/academia-powerfit.git
Acesse a pasta do projeto:

Bash
cd academia-powerfit
Abra o arquivo index.html em seu navegador de preferência.
